# Employee Daily Status Web Application

##  Project Description
This is a lightweight Employee Daily Status Web Application built using Core Java HTTP Server.

##  Features
- User Registration & Login
- Employee Dashboard
- Daily Task Submission (Title, Description, Date, Time, Status, Progress)
- Manager Dashboard (View all employee status)
- Styled UI using HTML & CSS
- File-based database storage

##  Technologies Used
- Java (JDK 17)
- Built-in HTTP Server
- HTML
- CSS
- File Handling

##  How to Run
1. Compile:
   javac EmployeeWebApp.java
2. Run:
   java EmployeeWebApp
3. Open browser:
   http://localhost:8080
